# Blinkit Sales & Customer Analytics Dashboard

An interactive Power BI dashboard built to analyze sales performance, customer behavior, product performance, and order trends using 250K+ synthetic Blinkit-style transaction records.

## 📊 Dashboard Preview

![Blinkit Dashboard](Blinkit-Sales-Analytics/Blinkit Dashboard Preview.jpg)

## 🎯 Key KPIs

- Total Revenue: ₹17.42M
- Total Orders: 250K
- Total Quantity: 481K
- Total Customers: 77K

## 🔍 Analysis Covered

- Revenue Trend
- Sales by Category
- Top 10 Products by Revenue
- Sales by City
- Orders by Hour
- Customer Type Analysis
- Orders by Payment Method
- Interactive filtering by date, city, brand, customer type, payment method, zone, order status, and delivery time

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Analysis
- Data Visualization
- Data Modeling

## 📁 Files

- `Blinkit Dashboard.pbix` – Power BI dashboard
- `Blinkit Dashboard.png` – Dashboard preview

## 📌 Dataset

The dataset used in this project is synthetic Blinkit-style data created for learning and portfolio purposes. It does not contain confidential or proprietary Blinkit data.

## 💡 Key Insights

- Revenue performance varies across cities and product categories.
- Customer purchasing behavior differs across customer types.
- Order activity changes significantly throughout the day.
- A small group of products contributes significantly to overall revenue.
- Payment preferences vary across customers.
