# 📊 Amazon Sales Analysis Dashboard

## 📌 Project Overview

This project analyzes Amazon sales data using Power BI to uncover business insights related to sales performance, customer behavior, product trends, and order status.

## 🎯 Objective

The goal of this dashboard is to help business users monitor sales performance, identify top-performing products, analyze customer purchasing behavior, and support data-driven decision-making.

## 🛠️ Tools Used

- Microsoft Power BI
- DAX
- Power Query
- Microsoft Excel
- SQL Server

## 📈 Dashboard Features

- Total Revenue
- Total Orders
- Average Order Value
- Total Customers
- Order Status Analysis
- Monthly Sales Trend
- Category-wise Sales
- Top 10 Products
- Top Customers
- Region-wise Sales
- Interactive Slicers

## 📊 KPIs

- Total Revenue
- Total Orders
- Average Order Value
- Total Customers
- Cancelled Orders
- Delivered Orders
